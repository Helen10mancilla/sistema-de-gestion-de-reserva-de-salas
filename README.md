# Sistema Web de Gestión de Reservas de Salas — UNIAJC

## Descripción

Aplicación web desarrollada como proyecto de grado del programa Tecnología en Sistemas de Información de la Institución Universitaria Antonio José Camacho.

El sistema busca facilitar la gestión de reservas de salas de la biblioteca universitaria mediante una plataforma que permite consultar la disponibilidad de los espacios, registrar reservas y administrar la información correspondiente.

## Objetivo

Desarrollar una aplicación web que facilite la organización, consulta y administración de las reservas de salas de la biblioteca, centralizando las operaciones en un único sistema.

## Funcionalidades

### Estudiantes y docentes
- Inicio de sesión.
- Consulta de disponibilidad de los espacios.
- Selección de fechas para las reservas.
- Registro de reservas.
- Modificación y cancelación de reservas.

### Administrador
- Acceso al panel administrativo.
- Gestión de reservas.
- Administración de la disponibilidad de los espacios.
- Generación de reportes de reservas por rango de fechas.

## Tecnologías utilizadas

- **Backend:** PHP.
- **Base de datos:** MariaDB/MySQL.
- **Servidor local:** Apache mediante XAMPP.
- **Frontend:** HTML, CSS y JavaScript.
- **Control de versiones:** Git y GitHub.

## Requisitos para ejecutar el proyecto

- XAMPP con Apache y MySQL/MariaDB.
- Navegador web actualizado.
- Base de datos del proyecto.
- Archivos fuente de la aplicación.

## Instalación local

1. Instalar y abrir XAMPP.
2. Copiar la carpeta del proyecto en `C:\xampp\htdocs\`.
3. Iniciar los servicios Apache y MySQL.
4. Crear la base de datos e importar el archivo SQL del proyecto.
5. Configurar la conexión a la base de datos en los archivos de configuración, utilizando las credenciales locales.
6. Abrir el navegador y acceder a `http://localhost/programacion_salas/`.

Los pasos pueden variar según la configuración de la instalación.
